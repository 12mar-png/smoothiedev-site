# SmoothieDev — Site Institucional

Site institucional fictício da SmoothieDev, uma startup de desenvolvimento de software e apps, criado como atividade de portfólio.

## Estrutura do projeto

```
smoothiedev-site/
├── index.html       (Home)
├── sobre.html        (Sobre Nós)
├── servicos.html      (Serviços)
├── cases.html        (Cases)
├── contato.html       (Contato)
├── css/
│   └── style.css      (folha de estilo externa, única para todas as páginas)
└── README.md
```

## Tecnologias

- HTML5 semântico
- CSS3 puro (sem frameworks), com variáveis, Flexbox e Grid
- Abordagem Mobile-First com Media Queries
- Fontes web: Space Grotesk (títulos) e Inter (corpo de texto), via Google Fonts

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador. Não há dependências ou build necessário.
